# 成年亲密场面调度与表演参考

本文件用于成年、自愿、合法授权的亲密剧情。它把亲密场面视为表演、空间和关系调度问题，而不是动作词库。

## 1｜心理与叙事原则

### 1.1 行为必须有叙事功能

亲密行为至少承担一项：

- 确认关系；
- 暴露需求；
- 改变权力或信任；
- 解决或加深冲突；
- 形成反转；
- 表达告别、和解或余韵。

若删除亲密行为后人物关系完全不变，场面通常缺乏戏剧功能。

### 1.2 不把身体反应当成心理结论

镜头可呈现呼吸、视线、肌肉、距离和声音，但不得自动推断：

- 身体反应 = 同意；
- 沉默 = 同意；
- 僵住 = 享受；
- 哭泣 = 欲望；
- 醉态 = 可作决定。

同意通过明确语言、主动回应、持续参与、可撤回边界和停止后的确认表达。

### 1.3 亲密张力

张力来自：

- 意图与克制；
- 距离缩短；
- 视线先行；
- 动作发起后等待回应；
- 声音和呼吸逐渐改变；
- 角色选择继续、停下或改变。

不是来自连续堆叠更强动作。

## 2｜场面调度卡

每个亲密场面先填写：

```text
场景：
角色与关系：
所有角色成年确认：
同意与边界：
场面叙事功能：
主动者 / 回应者：
情绪起点：
触发：
情绪转折：
结束状态：
空间锚点：
服装初始状态：
允许露出：
禁止露出：
声音边界：
```

## 3｜身体几何，而非标签

姿态用可拍摄几何描述：

- 人物面对 / 背对 / 并排；
- 站立 / 坐 / 跪 / 仰卧 / 侧卧；
- 主要承重点；
- 骨盆、肩、膝、手的方向；
- 两人接触点；
- 视线是否可见；
- 摄影机能否看清关系；
- 从上一姿态到下一姿态的转换路径。

动作名称仅作为内部索引。正式输出必须写清几何与过渡，不得只写“骑乘式”“后入式”等标签。

## 4｜姿态转换

任何转换按以下顺序写：

1. 发起者给出语言或动作信号；
2. 回应者确认并改变承重点；
3. 手或脚找到新的支撑；
4. 躯干转动；
5. 另一侧肢体跟随；
6. 两人重新建立平衡和视线；
7. 镜头在动作中切换或保持连续；
8. 声音和呼吸不中断；
9. 服装、配饰和道具状态更新。

禁止从一种姿态瞬移到另一种姿态。

## 5｜接触地图

每一拍只指定必要接触：

```text
谁的哪一只手
→ 接触对方或物件的什么位置
→ 沿什么路径移动
→ 对方如何回应
→ 接触何时停止或改变
```

同一时间变量过多会降低生成稳定性。高复杂度接触应拆拍。

## 6｜主动与回应

亲密互动采用反应链：

```text
A 靠近并停在可回应距离
→ B 以视线 / 语言 / 手部动作确认
→ A 才继续
→ B 的重心、呼吸或手部进一步回应
```

若剧情中角色撤回、停顿或改变边界，另一方必须立即停止或调整。不要把边界写成调情障碍。

## 7｜表演强度

分四档：

### 低强度

- 视线停留；
- 距离缩短；
- 指尖或手背短暂接触；
- 呼吸基本平稳；
- 适合建立和克制。

### 中强度

- 主动靠近；
- 持续接触；
- 呼吸和肩颈明显变化；
- 对白减少；
- 适合关系确认和推进。

### 高强度

- 全身重心参与；
- 动作节奏加快；
- 声音更近、更碎；
- 镜头减少无关信息；
- 必须有明确触发和稳定支撑。

### 余韵

- 呼吸逐步恢复；
- 手部由抓握转为支撑或安抚；
- 视线重新聚焦；
- 空间声重新进入；
- 用一个关系动作收束。

强度不能无触发瞬间跳级。

## 8｜露出与镜头策略

在项目配置中明确：

- 非露骨；
- 暗示性；
- 部分裸露；
- 明确成人内容。

镜头策略：

- 关系优先：面部、手、距离和重心；
- 动作优先：全景或中景先建立身体几何；
- 局部镜头：只在不可替代的信息点使用；
- 遮挡：前景、布料、身体、家具或景深；
- 镜面：先建立真实方向，避免双主体错位；
- 复杂明确接触：减少运动镜头、遮挡和同步动作数量。

不因内容等级自动要求局部特写。

## 9｜服装与配饰连续性

维护状态表：

```text
Sequence：
角色：
上装：
下装：
内层：
鞋：
眼镜：
项链 / 耳环 / 戒指：
脱卸动作：
物件落点：
下一段状态：
```

服装变化必须有可见动作和合理时间。  
配饰默认保持，只有剧情明确摘除时更新。  
脱下的物件必须有落点，后续镜头不能自行回到身上。

## 10｜声音

声音来自：

- 房间环境；
- 布料；
- 家具受力；
- 呼吸；
- 口部接触；
- 身体接触；
- 对白；
- 后期音乐。

拟声词不是质量指标。只在用户或目标模型需要时使用，并服从材质、距离、节奏和空间混响。不能让声音比画面行为更夸张。

## 11｜成人心理学研究表述

若用户的目标是研究或分析：

- 区分可观察行为与心理解释；
- 明确样本、情境和推断边界；
- 不用性别刻板印象解释主动、顺从、嫉妒或满足；
- 不把成人影视表演当成真实生理或关系规范；
- 不从单一画面诊断人格、创伤、依恋或性偏好；
- 用“镜头呈现”“角色设定”“表演编码”而非“现实中一定”。

## 12｜调度 QA

- 是否明确所有人成年；
- 是否存在持续同意；
- 是否每个动作有发起与回应；
- 是否身体重心符合物理；
- 是否姿态转换可执行；
- 是否服装和配饰可追踪；
- 是否镜头先建立空间；
- 是否局部镜头有叙事理由；
- 是否情绪强度有触发；
- 是否声音有物理来源；
- 是否结束后有明确关系状态。
